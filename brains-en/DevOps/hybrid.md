# Hybrid Cloud

## Hybrid Cloud

Clouds are categorized by their service model into:
1. Public
2. Hybrid
3. Private
4. Community

Among these, a hybrid cloud is a computing environment that combines **private cloud** and **public cloud** to share data and applications. Hybrid computing refers to providing businesses with the ability to seamlessly extend from on-premise environments to the public cloud to handle overflows when computing and processing demands fluctuate, without accessing all data from third-party data centers.

In other words, by leveraging this, customers can securely store critical business applications and data on-premise behind the company firewall, while flexibly computing basic and non-critical tasks in the public cloud.

## Hybrid Cloud Architecture
![](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Ft1.daumcdn.net%2Fcfile%2Ftistory%2F992D35415E19618613)

- It is a technology that links the internal corporate environment implemented on-premise with external clouds, allowing for **secure storage of sensitive information internally**, while **leveraging the cloud for flexible computing of basic and non-critical information**.
- Using a hybrid cloud in this way not only allows businesses to expand their computing resources, but also eliminates the need for separate capital expenditure when there's a short-term surge in data processing, or when critical data and local resources need to be secured.
- In other words, from a business perspective, it is the optimal platform that allows for the utilization of **resources and equipment that might otherwise remain idle for long periods**, while minimizing the risk of data exposure, and providing all the benefits of cloud computing.
