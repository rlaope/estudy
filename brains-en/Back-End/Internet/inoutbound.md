# Inbound, Outbound

Inbound and outbound refer to the **direction of traffic movement between networks**.

### Inbound
Inbound traffic is **information entering the network**

Messages traveling from a client to a server
> e.g., When saving an attachment to the server

### Outbound
Outbound traffic is **information leaving the network**

Processing a client's request and messages traveling back from the server to the client
> e.g., When downloading an attachment
