3. Since the SLD can be omitted, domain structures are categorized into 2-level and 3-level depending on its presence.

## What is a Domain Name
As previously defined, a domain name is
  
an internet address that makes IP addresses easier to understand by using text.

> In a broad sense, a domain name refers to a hostname that identifies a computer on a network, and in a narrow sense, it refers to a name registered with a domain registry. Collectively, these are sometimes called `web addresses`.
